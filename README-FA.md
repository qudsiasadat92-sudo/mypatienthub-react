# MyPatientHUB — نسخهٔ نهایی دفاع

## اجرا

ZIP را Extract All کنید. فولدری را در VS Code باز کنید که **package.json** داخل آن باشد.

```powershell
npm install
npm run dev
```

آدرس ترمینال را در مرورگر باز کنید. اگر ENOENT دیدید، با `dir package.json` بررسی کنید که ترمینال در فولدر درست است.

برای ساخت نسخهٔ نهایی:

```powershell
npm run build
```

## ورود برای ارائه

هر ایمیل با شکل درست، مانند `name@gmail.com`، و هر رمز غیرخالی پذیرفته می‌شود. ورود به حساب نمونه محدود نیست. رمز خالی یا تنها فاصله پذیرفته نمی‌شود.

Show/Hide رمز را نمایش یا پنهان می‌کند. Remember me جلسه را نگه می‌دارد و Log out آن را پاک می‌کند. این ورود برای نمایش فرانت‌اند است و حساب واقعی ایجاد نمی‌کند؛ رمز ذخیره یا ارسال نمی‌شود.

## تغییرات نهایی

- پس‌زمینهٔ موج‌دار و لوگوی سایت نمونه برای هماهنگی ظاهری اضافه شدند.
- ظاهر کارت‌ها، رنگ‌ها، فاصله‌ها، تایپوگرافی، فرم ورود، محصولات، چت و حساب زیباتر شدند.
- عکس هر شش دوا در کارت‌ها، جدول و جزئیات محصول استفاده می‌شود.
- باکس Download و آیکون‌های Apple و Android مطابق نمونه بازگردانده شد. لینک واقعی اپ برای این پروژهٔ نمایشی موجود نیست.
- Explore Demo و توضیحات فنی تکراری از صفحه‌های ارائه حذف شدند.
- جستجوی داکتر، شهر، تخصص، کلینیک، محصول و صفحات برنامه فعال است.
- داکتر یا کلینیک انتخاب‌شده حتی بعد از ورود به فرم رزرو منتقل می‌شود.
- تاریخ گذشته و نوبت تکراری پذیرفته نمی‌شود؛ امکان لغو نوبت اضافه شده است.
- مراحل ثبت وابستگان و تاریخ تولد بررسی می‌شوند؛ پروفایل فقط با Save ذخیره می‌شود.
- جستجوی محصولات شناسه‌ها را تغییر نمی‌دهد؛ جزئیات محصول عکس همان محصول را نشان می‌دهد.
- داکترها در کارت‌های منظم نمایش داده می‌شوند؛ کارت‌ها در موبایل یک ستون دارند.
- داده‌های ناسازگار ذخیره‌شدهٔ نوبت‌ها به مقدار اولیه برمی‌گردند تا برنامه خراب نشود.

## فایل‌های مهم

- `src/App.jsx`: مسیرها و محافظت نمایشی صفحه‌ها
- `src/Hub.jsx`: منطق فعال و اجزای مشترک
- `src/hub.css`: استایل فعال
- `src/pages/`: ورودی صفحه‌های متصل به مسیرها
- `src/data/`: اطلاعات فعال داکتر، کلینیک و دواخانه
- `public/images/`: تصاویر محلی
- `IMAGE-SOURCES.json` و `MEDICINE-PHOTO-SOURCES.json`: منابع تصاویر
- `DEFENSE-GUIDE-FA.md`: ترتیب کوتاه ارائه

## ماهیت پروژه

این پروژهٔ نمایشی فرانت‌اند است. داکترها، مراکز، قیمت‌ها و معلومات صحی نمونه‌اند؛ عکس‌ها معرف اشخاص نام‌برده نیستند. ورود، نوبت، پیام، پروفایل و صورتحساب در مرورگر نمایش و ذخیره می‌شوند؛ پرداخت یا پیام واقعی به داکتر انجام نمی‌شود. حفاظت مسیرها یک جریان نمایشی است و امنیت واقعی حساب محسوب نمی‌شود.
نقشهٔ OpenStreetMap اینترنت می‌خواهد؛ مختصات موقعیت ذخیره نمی‌شود. عکس‌ها داخل پروژه هستند.

## بررسی انجام‌شده

ورود خالی، ایمیل نادرست، رمز فاصله‌ای، نمایش رمز، ذخیره ایمیل، فیلتر شهر و تخصص، تغییر نقشه و فهرست، جزئیات دواخانه، بستن با Escape و صفحه‌بندی دواها در محیط DOM آزمایش شدند. Build تولیدی موفق است. بررسی تصویری کمپیوتر و موبایل این نسخه در مرورگر واقعی انجام شد.

## اصلاحات بررسی استاد
- تصویر داشبورد در قاب منظم و واکنش‌گرا تنظیم شد.
- نمودارهای داشبورد با Recharts ساخته شده‌اند؛ دارای محور، tooltip و انتخاب بازه‌اند. داده‌های صحی و سهم‌ها نمونه‌اند؛ نمودار نوبت‌ها از نوبت‌های ذخیره‌شده خوانده می‌شود.
- خالیگاه سطر آخر تخصص‌ها و داکترها حذف شد.
- پنج عکس متفاوت مراکز طبی برای کلینیک‌ها اضافه شد؛ این عکس‌ها معرف نام نمونهٔ کلینیک نیستند.
- تصاویر Marketplace اندازهٔ یکسان دارند؛ نام و توضیحات با تصویر هماهنگ شد.
- کارت‌های My Account ارتفاع طبیعی دارند و معلومات رسیدها منظم نمایش داده می‌شوند.
- ظاهر کمپیوتر و موبایل در مرورگر واقعی بررسی شد؛ تست فیلترها، چارت‌ها، عرض تصاویر و جلوگیری از بیرون‌زدگی موفق بود.
