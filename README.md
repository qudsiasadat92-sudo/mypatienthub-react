# MyPatientHUB Afghanistan

A responsive healthcare frontend project for exploring doctors, clinics, and pharmacies across Afghanistan.

## Features

- Sign-in form with email and password validation
- Dashboard with interactive charts
- Doctor search by name, specialty, and city
- Clinic directory with list and map views
- Pharmacy directory and medicine search
- Healthy food marketplace
- Appointment booking and cancellation
- Chat interface
- Patient profile and dependent management
- Responsive design for desktop and mobile

## Technologies and Tools

- HTML, CSS, JavaScript, and JSX
- React
- React Router
- Recharts
- Vite and npm
- Local Storage and Session Storage
- OpenStreetMap
- Git and GitHub

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## About the Project

This project was developed as part of the Web Development and Coding pathway of the Youth Skills & Livelihoods Program at HBC.

It demonstrates frontend design and functionality. Provider profiles, prices, and health statistics are sample data. Saved information stays in the browser; live authentication, messaging, booking services, and payments are not connected.
